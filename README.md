# CHUBBY BOY VS ANNIE

A complete 2D top-down arena brawler: **5 Chubby Boys vs 5 Annie** — slow, tanky, hard-hitting heavies against fast, fragile, mobile skirmishers. Everything (characters, animations, VFX, map, UI, sounds) is generated by the asset pipeline in `tools/` and consumed by the game through `assets/manifest.js`. No placeholder graphics.

## Run it

Open `index.html` in a browser (double-click, or a local server). No build step, no network.

## Multiplayer (LAN / same machine)

1. Start the server (no dependencies, plain Node):

   ```
   node tools/multi_server.js        // port 8080, or pass another: node tools/multi_server.js 9000
   ```

2. Join:
   - On the host PC: open the game, choose **MULTIPLAYER**, enter your **name**, connect to `localhost:8080`.
   - Friends on the same network: simply open `http://<host-ip>:8080` in a browser (the server hosts the game too),
     or open the game file and connect to `ws://<host-ip>:8080`.

Multiplayer rules: **no bots** — you spawn into an empty arena and players appear as they join. Everyone picks a name,
a faction and a fighter (duplicates allowed, up to 12 per team). Team score is server-authoritative; first to 30 wins,
then scores reset for the next round. Hold **TAB** for the live scoreboard (with ping). Leave from the pause menu.

Technical: the server is a plain WebSocket relay + lobby (`tools/multi_server.js`, raw Node, zero packages).
Each client simulates its own fighter and broadcasts position/aim/animation at 20 Hz; attacks are resolved by the
attacker and applied by the victim (authoritative on own HP). Visual effects are replayed on every client from
`fx / aoe / warn / atk / dash / skill` events so ultimates look identical for everyone.

## Controls

| Input | Action |
|---|---|
| WASD | Move |
| Mouse | Aim |
| Left click (hold) | Basic attack / combo |
| Q / E / R | Skills 1–3 |
| F | Ultimate (needs full meter) |
| Space | Dash (i-frames) |
| ESC / P | Pause |
| M | Mute |
| F3 | Debug overlay |

First team to **30 eliminations** wins. Health regenerates after 4s out of combat; dead fighters respawn after 4s at their spawn pad with brief invulnerability.

## Factions (asymmetric by design)

| | Chubby Boys | Annie |
|---|---|---|
| HP | 170–220 | 92–128 |
| Speed | 54–74 | 108–127 |
| Damage | 26–40 | 17–26 per hit, fast |
| Knockback | High | Medium |
| Defense | High | Low |
| Dash CD | ~5s | ~2s |
| Wins via | Durability, damage, knockback, AoE | Speed, range, mobility, dodging |

**Chubby Boys** — Brawler (tank), Boxer (fast combos), Tank (heavy), Smasher (AoE), Master (balanced).
**Annie** — Runner (speed), Archer (ranged), Assassin (burst, brown-skinned, athletic), Mage (ranged AoE), Champion (balanced).

Each character has: idle, walk, run, attack, combo, hit, knockback, dash, death, 3 skills and an ultimate animation — plus a unique VFX kit and portrait/selection icon.

## Project layout

```
index.html          entry point
style.css           menus/HUD styling
js/                 config, assets, audio, map, vfx, entities, combat, ai, hud, menus, main
assets/
  characters/chubby/{brawler,boxer,tank,smasher,master}/<anim>.png
  characters/annie/{runner,archer,assassin,mage,champion}/<anim>.png
  vfx/{attacks,impacts,skills,ultimates}/...
  map/{tiles,environment}/...
  ui/{icons,portraits,menu}/...
  audio/*.wav       20 synthesized SFX
  manifest.js       generated manifest binding every file to the game
tools/
  gen_chars.py        character/portrait/icon generator
  gen_fx_map_ui.py    VFX + tileset + props + UI + SFX generator, builds manifest
  check_assets.py     verifies every asset exists, every reference resolves, everything is used
  multi_server.js     standalone multiplayer server (WebSocket relay + lobby + HTTP game host)
  smoke.js            headless Node test: boots the real game, simulates a full battle
  mp_smoke.js         end-to-end multiplayer test: real server + real game + fake second client
```

## Asset pipeline

1. `python tools/gen_chars.py` — renders all 10 characters (13 animations each, ~720 frames), portraits, icons.
2. `python tools/gen_fx_map_ui.py` — renders VFX, arena tiles, props, UI kit, menu background, synthesizes the SFX WAVs, and writes `assets/manifest.js`.
3. `python tools/check_assets.py` — asset integrity & usage audit.
4. `node tools/smoke.js` — headless runtime test (boot → battle → every skill/ult → end screen → restart).

Re-run 1–2 to regenerate art; the game always renders exactly what the manifest lists.
